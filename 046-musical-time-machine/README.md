# Musical Time Machine

## Description
Creates a Spotify playlist from Billboard Hot 100 hits for a date specified by the user using web scraping and Spotify API integration.

## Key Concepts
- Web scraping (BeautifulSoup)
- Spotify API
- Data extraction
- Playlist creation

## How to Run
```bash
python main.py
```

## Setup
- Obtain Spotify API credentials
- Configure authentication

## Features
- Scrapes Billboard Hot 100 for a date
- Creates Spotify playlist
- Adds top songs to playlist
- Automatic organization

## What You'll Learn
This project teaches:
- Web scraping with BeautifulSoup
- Spotify API authentication
- Playlist manipulation
- Data extraction and processing
- API integration workflows
