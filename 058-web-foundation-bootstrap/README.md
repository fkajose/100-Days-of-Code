# Tindog Website

## Description
A Bootstrap-based landing page for a dog dating app ("Tindog"), demonstrating modern web design with Bootstrap framework.

## Key Concepts
- Bootstrap framework
- Responsive design
- Component usage
- Front-end design

## How to Run
Open `index.html` in a web browser.

## Features
- Responsive layout
- Bootstrap components
- Modern design
- Mobile-friendly

## What You'll Learn
This project teaches:
- Bootstrap basics
- Grid system
- Bootstrap components
- Responsive web design
- Modern CSS frameworks
- Front-end design patterns
