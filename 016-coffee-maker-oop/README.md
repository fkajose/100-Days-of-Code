# Coffee Maker (OOP)

## Description
A refactored version of the coffee machine project using object-oriented design principles with improved architecture and class hierarchy.

## Key Concepts
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Designing class hierarchies
- Implementing inheritance
- Proper encapsulation practices
- Separating concerns into different classes
- Code reusability through inheritance
