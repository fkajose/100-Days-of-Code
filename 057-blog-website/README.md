# Blog Website

## Description
A Flask application that renders blog posts fetched from an external API, demonstrating dynamic content rendering.

## Key Concepts
- Flask routes
- External APIs
- Jinja templating
- JSON parsing

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Fetches posts from API
- Dynamic blog rendering
- Template inheritance
- Post display

## What You'll Learn
This project teaches:
- Fetching data from APIs
- Template rendering
- Jinja2 template language
- Dynamic content generation
- Flask application structure
