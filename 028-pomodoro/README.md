# Pomodoro Timer

## Description
A GUI-based timer implementing the Pomodoro Technique for time management: alternating work sessions with short and long breaks.

## Key Concepts
- Tkinter (GUI framework)
- Time module
- GUI updates
- State management

## How to Run
```bash
python main.py
```

## Features
- 25-minute work sessions
- 5-minute short breaks
- 15-minute long breaks after 4 work sessions
- Visual timer display
- Start and reset buttons

## What You'll Learn
This project teaches:
- Tkinter GUI development
- Time tracking and intervals
- Widget updates
- Button callbacks
- Building functional applications
