# Treasure Island: Mystic Lake

## Description
A text-based decision game with treasure-themed choices and branching storylines.

## Key Concepts
- Conditional statements (if/elif/else)
- Branching logic
- User input handling

## How to Run
```bash
python main.py
```

## What You'll Learn
This project introduces:
- Using conditionals to create branching narratives
- Decision trees in programming
- Creating interactive text-based experiences
- How different choices lead to different outcomes
