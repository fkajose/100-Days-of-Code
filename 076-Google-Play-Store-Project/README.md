# Google Play Store Data Analysis

## Description
Data analysis of app-store data from Google Play Store, exploring app metrics, categories, and performance patterns.

## Key Concepts
- Pandas analytics
- App store data
- Performance analysis
- Data insights

## How to Run
```bash
python analysis.py
# or open the Jupyter notebook
jupyter notebook analysis.ipynb
```

## Features
- App category analysis
- Rating analysis
- Download analysis
- Comparative metrics

## What You'll Learn
This project teaches:
- Real-world app analytics
- Categorical analysis
- Comparative statistics
- Data insight generation
- Pandas advanced operations
