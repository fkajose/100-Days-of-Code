# Turtle Race

## Description
Simulates a race between multiple turtles, with random movement each turn. The user can bet on which turtle will win.

## Key Concepts
- Turtle graphics
- Loops
- Random movement
- Game logic

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Animating multiple objects with turtle graphics
- Using loops for simulation
- Random number generation in games
- Game state management
- Determining winners
