# Blog with Users

## Description
A multi-user blog application with user authentication, protected routes, user-specific posts, and comment functionality.

## Key Concepts
- Flask-Login
- SQLAlchemy relationships
- User authentication
- Comment systems

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- User registration/login
- Create posts (authenticated users only)
- Protected routes
- Comments on posts
- User-specific content

## What You'll Learn
This project covers:
- Multi-user applications
- Database relationships
- Protected routes
- Comment systems
- User-generated content
