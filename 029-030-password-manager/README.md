# Password Manager

## Description
A GUI application that securely stores and retrieves saved passwords. Project 30 adds enhanced functionality with password search capabilities.

## Key Concepts
- Tkinter (GUI framework)
- File handling
- JSON data format
- User interface design

## How to Run
```bash
python main.py
```

## Features
- Save passwords for different websites
- Retrieve stored passwords
- Search functionality (Day 30)
- Simple and intuitive interface

## What You'll Learn
This project covers:
- Building complete GUI applications
- File operations and persistence
- JSON for data storage
- Password management concepts
- Data encryption basics (optional enhancements)
