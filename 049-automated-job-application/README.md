# Automated Job Application

## Description
Automates the job application process using Selenium by filling out job listing forms with user data and submitting applications.

## Key Concepts
- Selenium automation
- Form filling
- CSS selectors
- Browser interaction

## How to Run
```bash
python main.py
```

## Setup
- Configure application details
- Set job site credentials

## Features
- Finds job listings
- Fills application forms
- Submits applications
- Tracks submissions

## What You'll Learn
This project covers:
- Advanced Selenium usage
- Form element identification
- CSS selectors
- Handling multiple pages
- Error handling in automation
