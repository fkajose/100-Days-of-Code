# Hangman

## Description
A classic word-guessing game where players try to figure out a hidden word by guessing letters before running out of attempts. Includes ASCII art for visual feedback.

## Key Concepts
- While loops
- Module imports (random, hangman_art, hangman_words)
- List operations
- String methods

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Creating game loops with while statements
- Importing and using custom modules
- Managing game state and attempts
- Working with lists and sets
- String operations and checks
