# Backend Intro with Flask

## Description
An introductory Flask project demonstrating basic web server concepts and includes a timing decorator example for performance measurement.

## Key Concepts
- Flask basics
- Route handling
- Decorators
- Request/response cycle

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Basic route handling
- Timing decorator
- Function wrappers
- Server basics

## What You'll Learn
This project teaches:
- Flask application setup
- Creating routes
- Function decorators
- Performance timing
- Request handling
