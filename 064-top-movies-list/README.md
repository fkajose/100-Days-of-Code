# Top Movies List

## Description
A movie list app with ranking functionality and TMDB API integration for fetching movie details and ratings.

## Key Concepts
- Flask
- SQLAlchemy
- API integration (TMDB)
- Data management

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Add movies
- Rate and rank movies
- TMDB API integration
- Movie details display
- Persistent storage

## What You'll Learn
This project covers:
- External API integration
- Movie data handling
- Ranking algorithms
- SQLAlchemy relationships
- Complete web application
