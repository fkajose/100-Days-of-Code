# Caesar Cipher

## Description
Encrypts and decrypts text using the Caesar cipher technique, a simple substitution cipher that shifts letters by a fixed number of positions.

## Key Concepts
- Modulo operator (%)
- Nested loops
- String manipulation
- Character encoding

## How to Run
```bash
python main.py
```

## What You'll Learn
This project introduces:
- The modulo operator for wrapping values
- Nested loop structures
- Character manipulation and ASCII values
- Encryption and decryption concepts
- How classical ciphers work
