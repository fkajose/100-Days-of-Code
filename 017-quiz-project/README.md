# Quiz Project

## Description
A general knowledge quiz application with scoring system that fetches questions from an external API.

## Key Concepts
- Data structures
- APIs and external data
- Score tracking
- Question management

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Fetching data from APIs
- Managing quiz state
- Score calculation
- Displaying results
- Working with question banks
