# ISS Overhead Notifier

## Description
An application that tracks the International Space Station's position and alerts the user via email or SMS when it passes overhead.

## Key Concepts
- API integration
- Geolocation
- Email/SMS notifications
- Real-time tracking

## How to Run
```bash
python main.py
```

## Setup
- Configure your coordinates (latitude/longitude)
- Set up email or SMS credentials
- Run the application

## Features
- Fetches ISS position from API
- Calculates overhead passes
- Sends notifications
- Configurable location

## What You'll Learn
This project teaches:
- Working with multiple APIs
- Location-based calculations
- Notification systems
- Time zone handling
- Scheduled automation
