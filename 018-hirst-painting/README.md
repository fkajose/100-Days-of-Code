# Hirst Painting Project

## Description
Generates a Damien Hirst-inspired abstract painting with randomly colored dots using turtle graphics.

## Key Concepts
- Turtle graphics
- Random colors
- Loops and nested loops
- Art generation

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Using the turtle graphics module
- Creating visual output with loops
- Color manipulation and RGB values
- Random selection
- Generative art concepts
