# Habit Tracker with Pixela

## Description
A habit tracking application that uses the Pixela API to create visual graphs of daily habit completion over time.

## Key Concepts
- API integration
- Habit tracking
- Data visualization
- HTTP requests

## How to Run
```bash
python main.py
```

## Setup
- Create Pixela account
- Configure habit and tracking data
- Set up API credentials

## Features
- Track daily habits
- Create visual graphs
- Track over time
- API integration

## What You'll Learn
This project teaches:
- Working with Pixela API
- Creating and updating graphs
- Habit tracking logic
- HTTP request methods (POST, PUT, DELETE)
- Data persistence concepts
