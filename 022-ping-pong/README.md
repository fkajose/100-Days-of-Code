# Ping Pong

## Description
A two-player arcade-style Pong game where players control paddles to hit a ball back and forth while tracking scores.

## Key Concepts
- Classes
- Collisions detection
- Score tracking
- Game state management

## How to Run
```bash
python main.py
```

## Game Mechanics
- Player 1: W (up) and S (down) keys
- Player 2: Up and Down arrow keys
- Score points when opponent misses the ball
- First to reach target score wins

## What You'll Learn
This project teaches:
- Building two-player games
- Collision detection
- Paddle and ball physics
- Score tracking
- Game state management
