# Mail Merging

## Description
A utility that personalizes letters for multiple recipients by merging template text with individual names from a data source.

## Key Concepts
- File handling
- String manipulation
- Loops
- Data processing

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Reading and writing files
- String formatting and replacement
- Working with file paths
- Batch processing data
- Template-based text generation
