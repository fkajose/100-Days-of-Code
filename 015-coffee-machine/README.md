# Coffee Machine

## Description
A simulated coffee-ordering machine that tracks resources, accepts money, and dispenses drinks based on availability.

## Key Concepts
- Classes and objects
- Methods
- State management
- Dictionary operations

## How to Run
```bash
python main.py
```

## What You'll Learn
This project introduces:
- Object-oriented programming basics
- Creating classes to model real-world entities
- Managing object state
- Encapsulation principles
- Resource management
