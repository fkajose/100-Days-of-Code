# Personal Site with CSS

## Description
A styled personal website using CSS to control layout, colors, fonts, and visual design while maintaining semantic HTML structure.

## Key Concepts
- CSS selectors
- Layout techniques
- Typography
- Colors and styling

## How to Run
Open `index.html` in a web browser.

## Files
- `index.html` - HTML structure
- `style.css` - Styling

## What You'll Learn
This project teaches:
- CSS selectors and specificity
- Box model
- Flexbox or Grid basics
- Typography with CSS
- Color and background styling
- Responsive design introduction
