# Library Website

## Description
A book tracker web application for adding, rating, and deleting books, demonstrating CRUD operations with SQLAlchemy ORM.

## Key Concepts
- Flask
- SQLAlchemy ORM
- CRUD operations
- Database design

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Add books
- Rate books
- Delete books
- View library
- Persistent storage

## What You'll Learn
This project teaches:
- SQLAlchemy ORM basics
- Database relationships
- CRUD operations
- Query operations
- Flask-SQLAlchemy integration
