# Number Guessing Game

## Description
A game where the user guesses a random number with hints (higher/lower) until they find the correct number. Includes difficulty levels.

## Key Concepts
- While loops
- Conditionals
- Random number generation
- Attempts tracking

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Using while loops for repeating game logic
- Conditional branching for hints
- Random number generation
- Tracking game state (attempts)
- Creating interactive gameplay
