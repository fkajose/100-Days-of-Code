# Web App with WTForms

## Description
A Flask application demonstrating WTForms and Flask-WTF for form handling with Bootstrap styling for improved presentation.

## Key Concepts
- WTForms
- Flask-WTF
- Form validation
- Bootstrap integration

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- WTForms implementation
- Form validation
- Bootstrap styling
- Error handling

## What You'll Learn
This project teaches:
- WTForms framework
- Form validation
- CSRF protection
- Error message display
- Structured form handling
