# Secret Auction Program

## Description
An anonymous bidding application where multiple players can enter their bids, and the program announces the winner with the highest bid.

## Key Concepts
- Dictionaries
- Nested data structures
- Loops and input validation
- Finding maximum values

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Using dictionaries to store key-value pairs
- Nested data structures
- Creating repeating input prompts
- Comparing and finding maximum values
- Anonymous data handling
