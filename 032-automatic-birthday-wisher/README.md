# Automated Birthday Wisher

## Description
An application that automatically checks for upcoming birthdays and sends personalized birthday emails to recipients.

## Key Concepts
- Date handling
- Email (SMTP)
- File operations
- Automation

## How to Run
```bash
python main.py
```

## Setup
- Create a CSV file with birthday data
- Configure email credentials (securely)
- Schedule or run manually

## Features
- Reads birthday data from CSV
- Sends personalized emails
- Tracks sent emails
- Date comparison and matching

## What You'll Learn
This project covers:
- Working with dates and times
- Email sending via SMTP
- CSV file reading
- String formatting for emails
- Automation concepts
