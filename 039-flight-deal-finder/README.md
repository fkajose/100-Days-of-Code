# Flight Deal Finder

## Description
Finds discounted flight deals from specified origin to destination cities and notifies the user via email or SMS when deals are found.

## Key Concepts
- Web scraping
- APIs
- Flight comparison
- Notifications

## How to Run
```bash
python main.py
```

## Setup
- Configure desired routes
- Set price threshold for deals
- Configure notification method

## Features
- Monitors flight prices
- Finds discounted flights
- Sends notifications
- Tracks multiple routes

## What You'll Learn
This project teaches:
- Web scraping techniques
- Flight API integration
- Price monitoring
- Email/SMS notifications
- Scheduled task automation
