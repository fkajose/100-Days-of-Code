# Blog Website with Contact Form

## Description
A Flask blog application with a working contact form that accepts user input, validates it, and processes submissions.

## Key Concepts
- Flask forms
- HTML forms
- Request handling
- Data validation

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Blog posts display
- Contact form
- Form submission
- Email integration (optional)

## What You'll Learn
This project teaches:
- HTML form creation
- Flask request handling
- Form validation
- Data processing
- Email sending basics
