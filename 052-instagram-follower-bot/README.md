# Instagram Follower Bot

## Description
Follows accounts of a target user's followers using Selenium automation for social media growth strategies.

## Key Concepts
- Selenium automation
- Instagram interaction
- List processing
- Browser automation

## How to Run
```bash
python main.py
```

## Setup
- Configure target account
- Set Instagram credentials
- Adjust following parameters

## Warning
⚠️ This project is for educational purposes only. Automated interactions may violate Instagram's Terms of Service.

## What You'll Learn
This project teaches:
- Instagram automation
- Follower list navigation
- Following automation
- Account management
- Rate limiting considerations
