# Coffee and Wifi Website

## Description
A Flask application that tracks coffee shops and their WiFi quality, allowing users to add, rate, and search for coffee shops.

## Key Concepts
- Flask
- WTForms
- SQLite database
- CRUD operations

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Add coffee shops
- Rate WiFi quality
- Search functionality
- Database persistence
- User-friendly interface

## What You'll Learn
This project covers:
- Flask application structure
- WTForms integration
- SQLite database usage
- CRUD operations
- Data management
