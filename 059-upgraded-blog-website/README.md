# Upgraded Blog Website

## Description
An improved Flask blog site with a cleaner front-end design incorporating Bootstrap for modern styling and layout.

## Key Concepts
- Flask
- Bootstrap styling
- Template design
- Responsive layout

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Bootstrap styling
- Responsive design
- Blog post rendering
- Modern layout

## What You'll Learn
This project covers:
- Integrating Bootstrap with Flask
- Template styling
- Responsive design principles
- Modern web design
- CSS framework integration
