# Data Exploration

## Description
An exploratory data analysis project demonstrating data wrangling, cleaning, and initial analysis techniques with Pandas.

## Key Concepts
- Pandas
- Data wrangling
- Data cleaning
- Exploratory analysis

## How to Run
```bash
python main.py
# or open the Jupyter notebook
jupyter notebook exploration.ipynb
```

## Features
- Data loading
- Data cleaning
- Exploratory analysis
- Visualization

## What You'll Learn
This project teaches:
- Pandas fundamentals
- Data cleaning techniques
- Data exploration methods
- Missing value handling
- Data summarization
