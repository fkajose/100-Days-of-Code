# U.S. States Game

## Description
An interactive game where players guess U.S. state names and mark them on a map. Correct guesses are displayed on the map graphic.

## Key Concepts
- Pandas data analysis
- Data cleaning
- Coordinate systems
- CSV file handling

## How to Run
```bash
python main.py
```

## Game Mechanics
- Game displays a blank U.S. map
- Type state names to guess them
- Correctly guessed states are marked on the map
- Game continues until you're done or all states are found

## What You'll Learn
This project covers:
- Using Pandas for data manipulation
- Reading CSV files
- Data cleaning and organization
- Coordinate mapping
- Interactive graphics with Turtle
