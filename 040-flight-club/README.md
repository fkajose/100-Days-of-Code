# Flight Club

## Description
An automated flight deal monitoring and alert system that continuously checks for discounted flight deals and notifies subscribers.

## Key Concepts
- Web scraping
- Automation
- Data management
- Email notifications

## How to Run
```bash
python main.py
```

## Features
- Continuous flight price monitoring
- Deal detection
- Automated alerts
- Multi-user support

## What You'll Learn
This project covers:
- Advanced web scraping
- Background task automation
- Database operations
- Email notification systems
- Building scalable applications
