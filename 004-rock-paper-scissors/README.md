# Rock Paper Scissors

## Description
A classic hand game implementation with ASCII art and computer opponent.

## Key Concepts
- Lists
- Randomness (random module)
- Comparison logic

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Using lists to store choices
- Generating random selections
- Comparing user input with computer choices
- Creating game logic and win conditions
