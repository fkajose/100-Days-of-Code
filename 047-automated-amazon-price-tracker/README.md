# Automated Amazon Price Tracker

## Description
Tracks product prices on Amazon and sends email alerts when prices drop below a specified threshold.

## Key Concepts
- Web scraping (BeautifulSoup)
- Email automation
- Price monitoring
- HTTP requests

## How to Run
```bash
python main.py
```

## Setup
- Add Amazon product URLs to track
- Configure email credentials
- Set price threshold

## Features
- Scrapes Amazon product pages
- Tracks price changes
- Sends email alerts
- Handles multiple products

## What You'll Learn
This project covers:
- Web scraping with BeautifulSoup
- HTML parsing
- Email notifications
- Price comparison logic
- Automation best practices
