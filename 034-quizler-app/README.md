# Quizler App

## Description
A GUI-based multiple-choice quiz application that presents questions with answer options and tracks the user's score.

## Key Concepts
- Tkinter (GUI framework)
- JSON data format
- Data structures
- GUI state management

## How to Run
```bash
python main.py
```

## Features
- Display quiz questions
- Show answer options
- Track score
- Display results

## What You'll Learn
This project covers:
- Building interactive GUI applications
- Working with JSON data
- Button widgets and callbacks
- Canvas for dynamic content
- Quiz logic implementation
