# Cafe API

## Description
A REST API for cafe data and management, demonstrating RESTful principles and JSON-based API design.

## Key Concepts
- Flask
- REST APIs
- JSON
- HTTP methods

## How to Run
```bash
python main.py
```

API runs on `http://localhost:5000/`

## Features
- GET, POST, PUT, DELETE endpoints
- Cafe database
- JSON responses
- Error handling

## What You'll Learn
This project teaches:
- RESTful API design
- HTTP methods
- JSON responses
- Request/response handling
- API best practices
