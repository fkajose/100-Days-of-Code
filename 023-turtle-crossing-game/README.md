# Turtle Crossing Game

## Description
A cross-the-road game where the player controls a turtle and must navigate across traffic without getting hit. Difficulty increases as levels progress.

## Key Concepts
- OOP (Object-Oriented Programming)
- Game loops
- Collision detection
- Coordinate systems

## How to Run
```bash
python main.py
```

## Game Mechanics
- Use arrow keys to move the turtle
- Avoid cars moving across the screen
- Reach the top to advance to the next level
- Each level increases speed

## What You'll Learn
This project covers:
- Creating game classes (Player, Car Manager, Screen)
- Game loop implementation
- Collision detection algorithms
- Level progression
- Speed/difficulty scaling
