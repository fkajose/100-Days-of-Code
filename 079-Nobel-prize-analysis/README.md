# Nobel Prize Analysis

## Description
Analyzes Nobel Prize data across time periods, exploring winner statistics, fields, and historical trends.

## Key Concepts
- Data exploration
- Historical analysis
- Trend analysis
- Data storytelling

## How to Run
```bash
python analysis.py
# or open the Jupyter notebook
jupyter notebook nobel_analysis.ipynb
```

## Features
- Prize distribution over time
- Category analysis
- Geographic trends
- Historical patterns

## What You'll Learn
This project teaches:
- Historical data analysis
- Trend identification
- Storytelling with data
- Statistical exploration
- Pattern recognition
