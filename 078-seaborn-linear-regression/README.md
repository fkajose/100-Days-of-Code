# Seaborn Linear Regression

## Description
Regression examples and visualization using Seaborn, demonstrating linear regression concepts and statistical plotting.

## Key Concepts
- Seaborn
- Linear regression
- Statistical visualization
- Data relationships

## How to Run
```bash
python regression.py
# or open the Jupyter notebook
jupyter notebook regression.ipynb
```

## Features
- Linear regression models
- Seaborn visualizations
- Data fitting
- Statistical plots

This project teaches:
