# Flask Authentication

## Description
Demonstrates user authentication in Flask with registration, login, logout functionality, and password hashing for secure session management.

## Key Concepts
- Flask-Login
- Password hashing (werkzeug)
- Session management
- User authentication

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- User registration
- Login/logout
- Password hashing
- Session management
- Protected pages

## What You'll Learn
This project covers:
- User authentication systems
- Password hashing
- Flask-Login extension
- Session management
- Security best practices
