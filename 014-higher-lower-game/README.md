# Higher Lower Game

## Description
A game where you guess which celebrity has more followers than another. Uses data from an external API to provide real comparison data.

## Key Concepts
- APIs
- JSON data
- Web requests
- Conditional logic

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Making API requests
- Parsing JSON responses
- Working with external data sources
- Game logic with real-world data
- Comparison and ranking
