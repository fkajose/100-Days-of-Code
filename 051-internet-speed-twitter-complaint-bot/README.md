# Internet Speed Twitter Complaint Bot

## Description
Measures internet speed and automatically posts a complaint tweet if the connection is below expected speeds.

## Key Concepts
- Speed testing
- Selenium automation
- Twitter API/automation
- Conditional logic

## How to Run
```bash
python main.py
```

## Setup
- Configure expected download speed
- Set up Twitter credentials
- Configure speedtest integration

## Features
- Measures connection speed
- Compares to expected speeds
- Posts automated tweets
- Tracks complaint history

## What You'll Learn
This project teaches:
- Speed testing APIs
- Twitter automation
- Conditional alerting
- Internet diagnostics
- API integration
