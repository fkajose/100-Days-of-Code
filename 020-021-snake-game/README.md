# Snake Game

## Description
A classic Snake game implementation split into two parts: Part 1 covers snake movement and game loop setup, Part 2 adds food, collision detection, and scoring.

## Key Concepts
- Game loops
- Coordinates and movement
- Classes and objects
- Collision detection
- Score management

## How to Run
```bash
python main.py
```

## Game Mechanics
- Use arrow keys to move the snake
- Eat food to grow longer
- Avoid hitting walls and yourself
- Score increases with each food eaten

## What You'll Learn
This project covers:
- Building a complete game from scratch
- Object-oriented game design
- Managing game state
- Collision detection algorithms
- Game loop implementation
