# Blackjack

## Description
A card game where the player plays against the computer. The goal is to get a hand value closer to 21 than the dealer without going over.

## Key Concepts
- Functions
- Modules (random)
- Game logic
- Conditional statements

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Creating a complete game with functions
- Managing game state
- Using randomness in games
- Implementing game rules and logic
- Detecting win/loss conditions
