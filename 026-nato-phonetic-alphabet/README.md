# NATO Phonetic Alphabet

## Description
Converts user input into NATO phonetic alphabet code words. Takes regular text and outputs the corresponding NATO phonetic representation.

## Key Concepts
- Dictionaries
- String handling
- List comprehension
- Data structures

## How to Run
```bash
python main.py
```

## Example
Input: `hello`
Output: `Hotel, Echo, Lima, Lima, Oscar`

## What You'll Learn
This project teaches:
- Using dictionaries for mapping
- List comprehension for data transformation
- String iteration and character handling
- Working with structured data
- Error handling for invalid inputs
