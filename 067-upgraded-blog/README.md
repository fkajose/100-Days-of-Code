# Upgraded Blog

## Description
A blog application with complete CRUD functionality, CKEditor for rich text editing, and SQLite database persistence.

## Key Concepts
- Flask
- CKEditor
- SQLAlchemy
- CRUD operations

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Create blog posts
- Edit existing posts
- Delete posts
- Rich text editing (CKEditor)
- Persistent storage

## What You'll Learn
This project covers:
- CKEditor integration
- Rich text handling
- Complete CRUD implementation
- SQLAlchemy usage
- Database operations
