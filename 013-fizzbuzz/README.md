# FizzBuzz

## Description
A debugging practice project using the classic FizzBuzz problem to identify and fix common logic issues.

## Key Concepts
- Debugging techniques
- Testing and validation
- Conditional logic
- Modulo operator

## How to Run
```bash
python main.py
```

## What You'll Learn
This project focuses on:
- Debugging code systematically
- Testing outputs against expected results
- Identifying logical errors
- Using conditionals effectively
- The importance of testing
