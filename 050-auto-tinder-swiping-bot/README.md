# Auto Tinder Swiping Bot

## Description
Automates basic Tinder swiping actions using Selenium to like or pass on profiles without manual interaction.

## Key Concepts
- Selenium automation
- Browser automation
- Button automation
- Interaction patterns

## How to Run
```bash
python main.py
```

## Setup
- Configure Tinder account credentials
- Set swipe preferences

## Warning
⚠️ This project is for educational purposes only. Automated interactions may violate Tinder's Terms of Service.

## What You'll Learn
This project teaches:
- Automating user interactions
- Element waiting and synchronization
- Error handling
- Click automation
- Session management
