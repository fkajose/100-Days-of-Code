# Workout Tracker

## Description
Tracks workout data and nutrition information by integrating with fitness and nutrition APIs to log exercise and food intake.

## Key Concepts
- Sheety API
- Nutritionix API
- Fitness tracking
- Data logging

## How to Run
```bash
python main.py
```

## Setup
- Configure Sheety sheet for data storage
- Set up Nutritionix API credentials
- Link your fitness tracking accounts

## Features
- Log workouts
- Track calories
- Record nutrition data
- Store in spreadsheet

## What You'll Learn
This project covers:
- Sheety API for spreadsheet management
- Nutritionix API for nutrition data
- Data logging systems
- Fitness tracking concepts
- Multiple API integration
