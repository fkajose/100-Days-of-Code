# Miles to Kilometers Converter

## Description
A GUI-based converter that transforms distance measurements between miles and kilometers with a user-friendly interface.

## Key Concepts
- Tkinter (GUI framework)
- Event handling
- GUI widgets
- Window management

## How to Run
```bash
python main.py
```

## Features
- Simple input field for conversion
- Real-time conversion results
- Support for both directions (miles ↔ km)

## What You'll Learn
This project covers:
- Tkinter basics for GUI development
- Creating buttons and labels
- Event handling for user interactions
- Layout management
- Simple GUI applications
