# Rain SMS Alert

## Description
An application that checks weather forecasts and sends SMS alerts when rain is expected in the next 12 hours.

## Key Concepts
- APIs (weather and SMS)
- Weather data parsing
- Twilio integration
- Automation

## How to Run
```bash
python main.py
```

## Setup
- Get API key from weather service
- Set up Twilio account for SMS
- Configure your location

## Features
- Checks weather forecast
- Sends SMS alerts for rain
- Configurable time window
- Automated checks

## What You'll Learn
This project teaches:
- Weather API integration
- Twilio SMS API
- Data parsing
- Conditional notifications
- Scheduling automation
