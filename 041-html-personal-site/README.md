# HTML Personal Site

## Description
A personal landing page built with HTML, introducing semantic tags and basic web structure principles.

## Key Concepts
- HTML structure
- Semantic HTML tags
- Document organization
- Accessibility basics

## How to Run
Open `index.html` in a web browser.

## Files
- `index.html` - Main landing page

## What You'll Learn
This project teaches:
- HTML document structure
- Semantic HTML elements
- Proper nesting
- Text formatting
- Links and images
- Web accessibility basics
