# LEGO Data Analysis

## Description
Explores LEGO dataset to identify patterns, popular themes, and insights about LEGO sets over time.

## Key Concepts
- Data analysis
- Pandas
- Plotting
- Pattern recognition

## How to Run
```bash
python analysis.py
# or open the Jupyter notebook
jupyter notebook analysis.ipynb
```

## Features
- Dataset exploration
- Pattern identification
- Visualizations
- Comparative analysis
- Trend analysis

## What You'll Learn
This project teaches:
- Real-world dataset analysis
- Data storytelling
- Visualization techniques
- Pattern identification
- Statistical analysis
