# Semmelweis Analysis

## Description
Reproduces a famous historical medical dataset analysis about Ignaz Semmelweis and hand-washing in childbirth, demonstrating data cleaning and statistical analysis.

## Key Concepts
- Data cleaning
- Statistics
- Historical analysis
- Medical data

## How to Run
```bash
python analysis.py
# or open the Jupyter notebook
jupyter notebook semmelweis.ipynb
```

## Features
- Historical data analysis
- Data cleaning
- Statistical testing
- Medical insights

## What You'll Learn
This project teaches:
- Data cleaning techniques
- Statistical testing
- Medical data analysis
- Historical research
- Data-driven conclusions
