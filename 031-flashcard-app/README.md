# Flashcard App

## Description
An interactive flashcard application for practicing vocabulary using a GUI. Cards show questions on one side and answers on the flip.

## Key Concepts
- Tkinter (GUI framework)
- File handling
- Data persistence
- User interaction

## How to Run
```bash
python main.py
```

## Features
- Display flashcards with questions and answers
- Track progress through the deck
- Save progress across sessions
- File-based data storage

## What You'll Learn
This project teaches:
- Building interactive Tkinter applications
- Image handling in GUI
- File-based data persistence
- Timer implementation
- Progress tracking
