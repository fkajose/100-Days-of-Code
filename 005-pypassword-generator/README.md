# Password Generator

## Description
Generates a random password by combining letters, numbers, and symbols in varied quantities.

## Key Concepts
- Loops
- List manipulation
- String concatenation
- Random selection

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Iterating through sequences with loops
- Manipulating lists
- Combining random selections
- Creating secure password patterns
