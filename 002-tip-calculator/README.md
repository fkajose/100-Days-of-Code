# Tip Calculator

## Description
Splits a bill among a number of people, calculating each person's share and tip amount.

## Key Concepts
- Arithmetic operations
- F-strings for formatted output
- Float data types

## How to Run
```bash
python main.py
```

## What You'll Learn
This project covers:
- Performing mathematical calculations
- Working with decimal numbers
- Formatting output with f-strings
- Taking user input for calculations
