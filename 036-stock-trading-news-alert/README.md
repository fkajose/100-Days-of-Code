# Stock Trading News Alert

## Description
Monitors stock prices and sends email alerts with relevant news summaries when significant price movements are detected.

## Key Concepts
- APIs (stock and news)
- XML/JSON parsing
- Email notifications
- Data monitoring

## How to Run
```bash
python main.py
```

## Setup
- Configure stock symbols to monitor
- Set API keys for stock and news services
- Configure email credentials

## Features
- Tracks stock prices
- Detects significant movements
- Fetches related news
- Sends email alerts

## What You'll Learn
This project covers:
- Stock market APIs
- News API integration
- XML/JSON data parsing
- Email composition and sending
- Price monitoring logic
