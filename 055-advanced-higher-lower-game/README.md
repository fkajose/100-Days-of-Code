# Advanced Higher Lower Game

## Description
A number-guessing web application built with Flask that provides GIF feedback based on whether guesses are correct or incorrect.

## Key Concepts
- Flask routes
- HTML templates
- Route parameters
- External APIs (GIF)

## How to Run
```bash
python main.py
```

Then navigate to `http://localhost:5000/`

## Features
- Web-based guessing game
- Dynamic GIF responses
- Route parameters
- Jinja templating

## What You'll Learn
This project covers:
- Flask route handling with parameters
- Template rendering
- Passing data to templates
- External API calls
- Game state management in web apps
