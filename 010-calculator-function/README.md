# Calculator

## Description
A simple calculator with basic arithmetic operations (add, subtract, multiply, divide) that performs calculations through function-based design.

## Key Concepts
- Functions
- Function arguments and parameters
- Return values
- Dictionaries for operation mapping

## How to Run
```bash
python main.py
```

## What You'll Learn
This project teaches:
- Defining and calling functions
- Using functions to organize code
- Passing arguments and returning values
- Using dictionaries to map operations
- Handling mathematical operations
